# Lessons

Мой репозиторий с учебными проектами по C#. Учусь по курсу SimpleCode, сюда складываю всё, что пишу в процессе (домашки, эксперименты, мини-проекты).

## Что тут есть:

- **AverageOfTwo** — вычисляет среднее арифметическое двух чисел. Есть проверка на то, что ввели именно число, а не букву.
- **CalculatorSwitch** — простой калькулятор на `switch`. Обрабатывает деление на ноль.
- **CalculatorIfElse** — тот же калькулятор, но на `if/else` (делал, чтобы сравнить оба подхода).
- **Converter** — конвертер рублей в доллары и евро. Округляет до двух знаков после запятой.
- **EvenOrOdd** — проверяет число на чётность. Сделан через тернарный оператор в одну строку.
- **EvenOddCounter** — считает количество чётных и нечётных чисел в заданном диапазоне. Есть проверка на правильность ввода границ.
- **SumOfThree** — находит сумму и произведение трёх чисел.
- **NestedLoopsTriangles** — рисует в консоли четыре разных треугольника с помощью вложенных циклов.
- **ArrayBasics** — базовая работа с массивами (ввод, вывод, сумма, среднее).
- **ArrayMinMax** — поиск минимального и максимального числа в массиве.
- **ArrayHomework** — вывод массива в обратном порядке и поиск суммы чётных чисел.
- **MatrixBasics** — двумерные массивы. Заполнение случайными числами, вывод в виде таблицы, поиск суммы и максимума.

## Что уже изучил по курсу:

- Основы: типы данных, переменные, ввод/вывод, арифметические операции.
- Условия: `if/else`, `switch`, тернарный оператор.
- Циклы: `while`, `for`, `do-while`.
- Функции и методы (включая рекурсию).
- Массивы: одномерные, двумерные.

Планирую дальше изучать зубчатые массивы, `List`, и перейти к ООП.
