# Lessons

Здесь лежат мои учебные проекты и домашние задания по C#. Учусь по курсу от SimpleCode, переношу сюда всё, что пишу по ходу.

## Проекты:

- **AverageOfTwo** — находит среднее арифметическое двух чисел (есть проверка на ввод букв).
- **CalculatorSwitch** — простой калькулятор с использованием `switch`.
- **CalculatorIfElse** — тот же калькулятор, но на `if/else` (делал для сравнения).
- **Converter** — конвертер рублей в доллары и евро.
- **EvenOrOdd** — проверяет число на чётность (сделано через тернарный оператор).
- **EvenOddCounter** — считает количество чётных и нечётных чисел в диапазоне.
- **NestedLoopsTriangles** — рисование в консоли четырёх видов треугольников вложенными циклами.
- **ArrayBasics** — базовая работа с массивами: ввод, вывод, сумма и среднее.
- **SumOfThree** — сумма и произведение трёх чисел.

## Что уже изучил:

- Переменные и типы данных
- Условия (if/else, switch, тернарник)
- Циклы (while, for, вложенные)
- Функции (методы)
- Массивы
